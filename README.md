# Ecommerce Sales Data Analysis

## Project Overview
This project analyses ecommerce sales data to understand
revenue patterns, product performance, customer behaviour,
and monthly sales trends.

## Objectives
- Analyse overall sales performance.
- Identify the top-performing category.
- Identify the product with the highest revenue.
- Explore customer transaction patterns.
- Analyse monthly revenue trends.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Findings
- Total recorded revenue: 1,552,071.00
- Total transactions: 12,575
- Unique customers: 25
- Top-performing category: Butchers
- Top product by revenue: Item_25_FUR

## Project Workflow
1. Data inspection
2. Data cleaning
3. Descriptive statistics
4. Exploratory data analysis
5. Data visualization
6. Business insights

## Conclusion
This project demonstrates how Python can be used
to explore ecommerce sales data and identify
meaningful business insights.
